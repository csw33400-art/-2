# 범용 회귀 분석 · ANN 예측 대시보드

CSV/Excel 데이터를 올리면 전통적 회귀 모델과 인공신경망(MLP)의 성능을 비교하고, 새 입력값으로 예측해 보는 Streamlit 앱입니다.

## 지원 모델

| 모델 | 조건 |
| --- | --- |
| 선형 회귀 | 항상 |
| 2차 다항 회귀 | X가 1개이고 서로 다른 X값이 3개 이상일 때 |
| 거듭제곱 회귀 (y = a·x^b) | X가 1개이고 X, Y가 모두 양수일 때 |
| 인공신경망 (MLP, 은닉층 2개) | 항상 (다변수 지원) |

## 화면 구성

- **성능 종합 비교**: 테스트 데이터 기준 R², RMSE, MAE와 학습 R²를 함께 보여줍니다. 학습 R²가 테스트 R²보다 크게 높으면 과적합을 의심할 수 있습니다.
- **잔차 분석**: 모델별 테스트 데이터 잔차 분포를 확인합니다.
- **실시간 예측**: X값을 입력하면 모든 모델의 예측값을 보여주고, 학습 범위를 벗어나면 경고합니다.

데이터가 8행 이상이면 사이드바에서 정한 비율만큼 테스트 세트를 따로 떼어 평가합니다. 그보다 적으면 전체 데이터로 평가합니다. 데이터를 올리지 않으면 콘크리트 압축강도 샘플 10행을 사용합니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```
