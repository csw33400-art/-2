# 범용 회귀 분석 · 머신러닝 예측 대시보드

CSV/Excel 데이터를 올리면 13가지 회귀·머신러닝 모델을 한 번에 학습해 성능을 비교하고, 잔차 진단·변수 영향 해석·일괄 예측까지 할 수 있는 Streamlit 앱입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 사이드바 설정

1. **데이터**: CSV/Excel 업로드(한글 CSV 인코딩 cp949 자동 인식, Excel 시트 선택). 업로드하지 않으면 샘플 3종(콘크리트 압축강도, 당뇨병 진행도, 비선형 합성 데이터) 중 선택.
2. **변수 선택**: Y 1개, X 여러 개.
3. **전처리**: 이상치 제거(IQR 또는 Z-score).
4. **학습/테스트 분할**: 테스트 비율, 랜덤 시드, 5-겹 교차검증 사용 여부.
5. **모델 선택과 하이퍼파라미터**: 모델별 규제 강도, 트리 깊이·개수, 커널, 은닉층 구조 등.

## 지원 모델

| 모델 | 조건 |
| --- | --- |
| 선형, 릿지, 라쏘, 다항(2~6차) 회귀 | 항상 |
| 결정 트리, 랜덤 포레스트, 그래디언트 부스팅 | 항상 |
| 서포트 벡터 회귀(SVR), K-최근접 이웃(KNN) | 항상 |
| 인공신경망(MLP, 은닉층 1~3개) | 항상 |
| 거듭제곱 회귀 y = a·x^b | X가 1개, X·Y 모두 양수 |
| 지수 회귀 y = a·e^(bx) | X가 1개, Y 모두 양수 |
| 로그 회귀 y = a + b·ln x | X가 1개, X 모두 양수 |

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| 📋 데이터 탐색 | 미리보기, 기술 통계량, 결측치, 상관계수 히트맵, 분포 히스토그램, 산점도, 산점도 행렬 |
| 📊 성능 비교 | 테스트·CV·학습 R², RMSE, MAE, MAPE, 과적합 격차, 학습 시간 표와 막대그래프. X가 1개면 적합 곡선, 2개면 3D 예측 곡면, 실제값 vs 예측값 산점도 |
| 📉 잔차 진단 | 예측값 vs 잔차, 잔차 히스토그램, 정규 Q-Q 플롯, Shapiro-Wilk 정규성 검정, Durbin-Watson 통계량, X변수별 잔차 |
| 🔍 모델 해석 | 선형 회귀 계수·표준오차·t값·p값과 회귀식, 곡선 회귀식, 순열 변수 중요도, 트리 중요도, 부분 의존도 그래프, ANN 학습 곡선 |
| 🔮 예측 | 값 입력 시 모든 모델 예측(최고 모델·상위 3개 평균·예측 범위), 학습 범위 밖 경고, 파일 업로드 일괄 예측 후 CSV 다운로드 |
| 💾 내보내기 | 평가지표·테스트 예측값·전처리 데이터 CSV, 학습된 모델 pickle 파일, 분석 설정 요약 |

## 평가 방식

데이터가 8행 이상이면 테스트 세트를 따로 떼어 학습에 쓰지 않은 데이터로 평가합니다. 교차검증(CV)은 학습 데이터 안에서 5번 나눠 검증한 값이라 데이터가 적을 때 더 안정적인 지표입니다. 학습 R²와 평가 R²의 차이(과적합 격차)가 크면 모델이 데이터를 외워버린 것일 수 있습니다.
