# 데이터 출처

## concrete.csv — 콘크리트 압축강도

- 출처: Yeh, I. (1998). *Concrete Compressive Strength* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5PK67
- 원 논문: I-C. Yeh, "Modeling of strength of high-performance concrete using artificial neural networks," *Cement and Concrete Research*, 28(12), 1998.
- 라이선스: Creative Commons Attribution 4.0 International (CC BY 4.0)
- 규모: 1,030행, 입력 변수 8개 + 목표 변수 1개, 결측치 없음
- 변경 사항: 열 이름만 한글(단위 포함)로 바꿨고 값은 원본 그대로입니다.

| 열 | 원본 변수 | 단위 |
| --- | --- | --- |
| 시멘트(kg/m3) | Cement | kg/m³ |
| 고로슬래그(kg/m3) | Blast Furnace Slag | kg/m³ |
| 플라이애시(kg/m3) | Fly Ash | kg/m³ |
| 물(kg/m3) | Water | kg/m³ |
| 고성능감수제(kg/m3) | Superplasticizer | kg/m³ |
| 굵은골재(kg/m3) | Coarse Aggregate | kg/m³ |
| 잔골재(kg/m3) | Fine Aggregate | kg/m³ |
| 재령(일) | Age | day |
| 압축강도(MPa) | Concrete compressive strength (목표 변수) | MPa |
