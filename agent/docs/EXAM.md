# 시험 대비: 내 코드로 보는 시험 범위

교수님 말씀(마지막 수업): 기말고사는 서술형이고, **답안을 각자의 코드와 비교한다.** 범위는 AI·딥러닝 기초, 통계 기초, 인공신경망 구조(Dense, 은닉층, 노드 수), 과적합과 데이터 분할, 역전파, 에포크, RMSE, 표준편차·정규분포, 경사하강법, 활성화 함수, LLM의 원리와 내 프로그램과의 연결.

각 항목은 **① 개념 → ② 내 코드의 어디에 있나 → ③ 답안에 쓸 문장** 순서입니다. 줄 번호는 작성 시점 기준입니다.

## 1. 인공신경망 구조: Dense, 은닉층, 노드 수

① 입력층(입력 변수 수만큼 노드) → 은닉층(노드 수는 설계자가 정함) → 출력층(회귀는 노드 1개). 뉴런 하나는 y = φ(Σωx + b).

② 과제 2 대시보드 `app.py` 327~332줄

```python
MLPRegressor(hidden_layer_sizes=tuple(cfg["ann_layers"]), activation=cfg["ann_act"],
             learning_rate_init=cfg["ann_lr"], alpha=cfg["ann_alpha"], max_iter=cfg["ann_iter"], random_state=seed)
```

- 은닉층 개수 1~3개, 첫 은닉층 노드 수 8~256(다음 층은 절반) → 기본값 `[64, 32]`
- 과제 3 `llm_chat/tools.py` 894~901줄은 같은 구조를 Keras `Dense`로 바꿔 보여 줌

③ "내 프로그램의 인공신경망은 입력 8개(콘크리트 배합) → 은닉층 64 → 32 → 출력 1(압축강도)이다. Keras로 쓰면 `Dense(64, activation='relu', input_shape=(8,))`, `Dense(32, activation='relu')`, `Dense(1)`이다. 가중치·편향 수는 8×64+64 + 64×32+32 + 32×1+1 = 2,689개다."

## 2. 활성화 함수

① 비선형성을 넣어 직선으로 못 푸는 관계를 배우게 함. 시그모이드(0~1), tanh(−1~1), ReLU(max(0,z)).

② 대시보드에서 `relu / tanh / logistic(시그모이드)` 선택(`cfg["ann_act"]`). 출력층은 회귀라 활성화 없음(MLPRegressor의 출력은 항등 함수).

③ "기본으로 ReLU를 썼다. 계산이 빠르고 양수 구간의 기울기가 1이라 기울기 소실이 적다. 시그모이드는 입력이 크면 기울기가 0에 가까워져 깊은 망에서 학습이 느려진다."

## 3. 에포크, 학습률, 경사하강법, 역전파

① 1 에포크 = 학습 데이터를 한 번 다 쓰는 것. 경사하강법: ω ← ω − η·∂E/∂ω (η = 학습률). 역전파: 연쇄법칙으로 출력층 오차를 거꾸로 전달해 ∂E/∂ω를 구함.

② `max_iter=cfg["ann_iter"]`(에포크, 기본 1000), `learning_rate_init=cfg["ann_lr"]`(학습률, 기본 0.001). 옵티마이저는 MLPRegressor 기본값 **Adam**(경사하강법의 한 종류). 대시보드 643줄 `mlp.loss_curve_`는 에포크마다의 손실 → 학습 곡선.

③ "`fit()`을 부르면 에포크마다 순전파 → 오차 계산 → 역전파로 기울기 계산 → Adam으로 가중치 갱신을 반복한다. 손실 곡선이 평평해지면 수렴한 것이고, 최대 에포크에 도달했는데도 내려가고 있으면 에포크를 늘려야 한다."

## 4. 과적합과 데이터 분할

① 학습 데이터만 잘 맞히고 새 데이터는 못 맞히는 현상. 학습·(검증)·테스트로 나눠 평가.

② 대시보드 220줄 `train_test_split(X, Y, test_size=test_pct / 100, random_state=seed)` (기본 80:20, 시드 42). 349줄 `KFold(n_splits=5)` 5겹 교차검증. 대시보드 결과표의 "과적합 격차(학습 − 평가 R²)". 과제 3 `tools.py` 873~875줄 딥러닝은 `early_stopping=True, validation_fraction=0.2`(학습 데이터의 20%를 검증용으로 떼어, 20번 연속 좋아지지 않으면 멈춤). `alpha`는 L2 규제.

③ "데이터를 80:20으로 나눠 20%는 학습에 쓰지 않고 평가에만 썼다. 마지막 과제 실행 결과 KNN은 학습 R² 0.997, 테스트 R² 0.777로 격차가 0.22라 과적합이고, 그래디언트 부스팅은 격차 0.06으로 일반화가 잘 됐다. 딥러닝은 검증 데이터로 조기 종료해 과적합을 막았다."

## 5. 정규화 (표준화)

① z = (x − 평균) / 표준편차. 변수 크기를 맞춰 학습을 안정시킴.

② 대시보드 `make_pipeline(StandardScaler(), MLPRegressor(...))`, 출력도 `TransformedTargetRegressor(transformer=StandardScaler())`로 표준화. 파이프라인 안에 있어서 평균·표준편차를 **학습 데이터에서만** 구함.

③ "시멘트(100~540)와 고성능감수제(0~32)처럼 크기가 다른 변수를 그대로 넣으면 큰 변수가 학습을 지배하므로, StandardScaler로 평균 0·표준편차 1로 맞췄다."

## 6. 평가지표: R², RMSE, MAE

② 대시보드 90~100줄 `safe_metrics`

```python
R2=r2_score(y_true, y_pred), RMSE=float(np.sqrt(mean_squared_error(y_true, y_pred))), MAE=float(mean_absolute_error(y_true, y_pred))
```

③ "RMSE = √(Σ(실제 − 예측)²/n)로 단위가 MPa라 '평균적으로 몇 MPa 틀리는지'로 읽는다. 내 인공신경망의 RMSE는 5.62 MPa, 선형 회귀는 9.80 MPa였다."

## 7. 통계: 표준편차, 정규분포, 이상치

② 대시보드 187~204줄 이상치 제거: IQR(Q1 − 1.5·IQR ~ Q3 + 1.5·IQR 밖 제거) 또는 Z-score(|z| > 3 제거).

③ "정규분포에서 평균 ±3σ 안에 약 99.7%가 들어가므로, |z| > 3인 값은 이상치로 보고 뺄 수 있다."

## 8. 선형회귀 vs 비선형 회귀 vs 인공신경망

② 대시보드 `build_estimator`: `LinearRegression`(최소제곱), `PolynomialFeatures`(다항), `CurveFitRegressor`(거듭제곱·지수·로그, `curve_fit` 비선형 최소제곱).

③ "콘크리트 데이터에서 선형 0.628 → 다항 0.784 → 인공신경망 0.877로 올랐다. 선형회귀는 비선형성과 다차원성을 표현하지 못한다는 한계가 있다."

## 9. 머신러닝 vs 딥러닝

③ "인공지능 ⊃ 머신러닝 ⊃ 딥러닝. 머신러닝은 데이터에서 규칙을 배우고, 딥러닝은 은닉층을 여러 개 쌓아 특징을 스스로 뽑는다. 내 프로그램의 딥러닝은 은닉층 4개(128-64-32-16)인데, 데이터가 1,030개로 적어 은닉층 2개 모델(0.877)보다 좋아지지 않았다(0.864)."

## 10. LLM의 원리 (RNN, LSTM, Transformer)

③ "LLM은 문장을 토큰으로 잘라 숫자 벡터로 바꾸고, 다음 토큰을 수만 개 후보 중 고르는 분류를 반복한다. RNN은 이전 상태를 다음 계산에 넘기고, LSTM은 게이트로 긴 문장의 기억을 유지한다. 지금의 GPT 계열은 문장 전체를 한꺼번에 보고 어느 토큰에 주목할지 계산하는 어텐션 기반 Transformer다. LLM도 결국 y = φ(Σωx + b) 뉴런을 아주 많이 쌓은 인공신경망이다."

## 11. 내 LLM이 프로그램과 연결되는 방식 (가장 중요)

② `agent/programs.py`의 `TOOLS`(도구 설명서 24개)와 `execute()`, `agent/core.py`의 `_loop_native()`

③ "LLM에게 프로그램 기능 목록을 JSON 스키마로 알려 주면(API), LLM이 실행할 기능과 값을 골라 돌려준다(명령). 프로그램이 그 기능을 실행하고 결과(R², 예측값 등)를 다시 LLM에게 보낸다(피드백). LLM은 결과를 보고 다음 기능을 고르거나 최종 설명을 한다. 예를 들어 '콘크리트 데이터로 신경망 학습하고 시멘트 350일 때 예측해줘'라고 하면 load_dataset → run_neural_network → predict를 차례로 실행한다. 과제 1·2 대시보드의 모델 코드는 파일을 AST로 읽어 그대로 실행했다."

"기억은 두 가지 방법 중 메모 방식을 썼다. 실행 기록과 사용자가 기억해 달라고 한 내용을 파일에 적고 다음 대화에서 읽힌다. 개념 질문은 강의 정리 조각을 TF-IDF로 검색해 근거로 건네는 RAG로 답하게 해 환각을 줄였다."

## 12. Streamlit의 한계

③ "Streamlit은 파이썬만으로 웹 화면을 쉽게 만들 수 있어 학생 프로젝트에 적합하지만, 접속자마다 파이썬 스크립트를 다시 실행하는 구조라 동시 접속자가 많으면 서버가 버티지 못한다. 실서비스는 별도 웹 서버와 프레임워크, 유료 호스팅을 쓴다. 또 무료 서버는 GPU가 없고 메모리가 약 2.7GB라 큰 LLM을 올릴 수 없어서, 큰 모델은 OpenRouter API로 쓰고 작은 모델(Qwen2.5-1.5B, 4비트 양자화)만 서버에 설치했다."
