# 오픈소스 LLM 챗봇: 자유 대화 + 채팅으로 실행하는 데이터 분석

화면에 **채팅창 하나만** 있는 챗봇입니다. 버튼·메뉴 없이 말로 시키면 선형회귀, 비선형회귀, 인공신경망, 딥러닝을 실행하고 그래프·표·해석을 채팅 안에 보여 줍니다. 오픈소스 언어모델을 웹 서버에 직접 설치해 실행하므로, 사용자는 아무것도 설치하지 않고 웹 주소로 바로 쓸 수 있습니다.

## 채팅 예시

| 하고 싶은 것 | 이렇게 입력 |
| --- | --- |
| 공개 데이터 쓰기 | "데이터 목록 보여줘", "자동차 연비 데이터 불러와", "펭귄 데이터 불러와", "집값 데이터 불러와" |
| 내 데이터 쓰기 | 입력창 📎로 파일 첨부(CSV·Excel·TSV·TXT·JSON), 데이터 주소 붙여넣기(CSV·구글 스프레드시트·GitHub), 표를 채팅창에 그대로 붙여넣기 |
| 숫자 직접 입력 | "x: 1, 2, 3, 4, 5 / y: 2.1, 3.9, 6.2, 8.1, 9.8" |
| 데이터 살펴보기 | "데이터 요약 보여줘", "열 목록 보여줘", "상관관계 보여줘", "마력 평균 알려줘", "무게랑 연비 산점도 그려줘" |
| 변수 정하기 | "Y는 압축강도, X는 시멘트랑 재령", "마력으로 연비 예측해줘", "물 빼고 해줘", "모든 변수로 해줘" |
| 선형회귀 | "선형회귀 해줘", "시멘트로 선형회귀 해줘" |
| 비선형회귀 | "비선형회귀 해줘", "3차 다항 회귀 해줘" |
| 인공신경망 | "인공신경망 학습해줘", "은닉층 32-16, tanh, 에포크 500으로 신경망 학습해줘" |
| 딥러닝 | "딥러닝으로 해줘" (은닉층 4개 128-64-32-16, 검증 데이터로 조기 종료) |
| 비교·예측·보고서 | "전부 비교해줘", "시멘트 300, 물 180, 재령 28일 때 예측해줘", "보고서 만들어줘" |
| 기억 | "지난번에 뭐 했지?" |
| 수업 개념 질문 | "오류역전파가 뭐야?" (언어모델이 답함) |

## 자유 대화 (ChatGPT처럼)

정해진 파일이나 명령이 없어도 아무 질문이나 할 수 있습니다. 선형회귀, 인공신경망, 딥러닝, 오픈소스, LLM 같은 주제는 물론 일반 대화도 언어모델이 답합니다.

- **참고 메모 검색(RAG)**: 15억 매개변수짜리 작은 모델은 혼자서는 설명이 부정확할 수 있습니다. 그래서 `knowledge.py`에 주제별 메모 20개를 두고, 질문에 나온 낱말로 관련 메모를 찾아 질문과 함께 모델에 넣어 줍니다. 가중치를 바꾸는 파인튜닝이 아니라 수업에서 배운 "메모를 붙여 주는 방식"입니다.
- **질문과 명령 구분**: "인공신경망은 어떻게 학습해?"는 설명을, "인공신경망 학습해줘"는 실제 학습을 실행합니다.
- **파일 없이 분석**: "y = 2x + 3 데이터 만들어서 선형회귀 해줘"처럼 식을 말하면 데이터를 만들어 분석하고, 숫자를 직접 적어도 됩니다.

## 어떤 데이터·어떤 변수든 인식

정해진 데이터만 쓰는 것이 아니라, 처음 보는 표도 바로 분석할 수 있게 만들었습니다.

| 기능 | 처리 방법 (`tools.py`) |
| --- | --- |
| 공개 데이터 9종 | 콘크리트, 당뇨병, 자동차 연비, 식당 팁, 펭귄, 캘리포니아 집값, 붓꽃, 와인, 합성 데이터 |
| 여러 파일 형식 | `read_table`: CSV·TSV·TXT·Excel·JSON, 한글 인코딩(UTF-8·CP949)과 구분자를 자동으로 맞춤 |
| 주소로 불러오기 | `load_url`: 구글 스프레드시트 공유 링크와 GitHub 파일 링크를 내려받기 주소로 바꿔서 읽음 |
| 채팅에 직접 입력 | `parse_pasted`: 엑셀에서 복사한 표, 쉼표·공백 구분 표, `x: 1, 2, 3 / y: …` 형태를 표로 바꿈 |
| 자동 정리 | `_clean`: "1,234"·"12%" 같은 글자 숫자를 숫자로, 글자 범주(성별 등)를 0/1 열로, 빈칸은 중앙값으로 채움 |
| 변수 이름 인식 | `_find`: 정확한 이름, 일부만 말한 이름("슬래그"), 한국어↔영어("몸무게" → weight), 오타, 순서("첫 번째 열") |
| 말로 변수 지정 | `parse_vars`: "마력으로 연비 예측", "무게에 따른 연비", "물 빼고" 같은 문장에서 X·Y를 정함 |

## 입력값에 따라 달라지는 결과

학습한 모델에 사용자가 말한 값을 넣어 그때그때 결과를 계산합니다. 정해진 예시만 보여 주는 것이 아닙니다.

| 말한 내용 | 동작 (`tools.py`) |
| --- | --- |
| "시멘트 350 물 170이면?" | `run_predict`: 말한 값으로 모든 학습 모델의 예측을 계산. 말하지 않은 변수는 평균으로 채우고 표에 표시 |
| "물을 200으로 바꾸면?" | 직전 입력값을 기억해 두고, 말한 변수만 바꿔 다시 계산 |
| "재령 7, 28, 90일 때 각각 예측해줘" | 값을 여러 개 주면 경우별 예측 표와 막대그래프 |
| "시멘트를 100에서 500까지 바꾸면?" | `run_sweep`: 한 변수를 범위로 바꿀 때 예측값이 변하는 곡선 (학습 범위 밖은 경고) |
| "물이 늘어나면 강도는?" | 숫자 없이 물어도 데이터 범위 전체로 변화 곡선을 그림 |
| "물시멘트비 = 물 / 시멘트 변수 만들어줘" | `add_variable`: 사용자가 정의한 식으로 새 변수를 만들어 입력 변수에 추가 |
| 입력 변수에 없는 변수의 값을 말함 | 그 변수를 입력에 추가하고 모델을 다시 학습한 뒤 예측 |

## 구조

```
사용자 채팅 ─▶ app.py: 말 해석(route)
                 ├─ 분석 명령 ─▶ tools.py 함수 실행 (scikit-learn) ─▶ 그래프·표·수치
                 │                                   └─▶ 언어모델이 결과를 두세 문장으로 해설
                 └─ 일반 질문 ─▶ 언어모델이 답함 (현재 분석 상태와 작업 기록을 함께 읽음)
```

- **분석 명령은 키워드로 인식**합니다. 무엇을 실행할지와 수치 계산은 프로그램이 맡아서, 작은 언어모델이 명령을 잘못 해석하거나 숫자를 지어내는 일을 막았습니다.
- **언어모델은 해설과 질문 응답**을 맡습니다. 계산된 수치를 받아 쉬운 말로 풀어 줍니다.
- **기억은 메모 방식**입니다. 실행한 작업을 파일에 적어 두고, 다음 대화에서 다시 읽습니다. 모델의 가중치는 바꾸지 않습니다.

## 언어모델

| 구분 | 사용한 것 |
| --- | --- |
| 모델 | Qwen2.5-1.5B-Instruct (Alibaba, Apache 2.0) / EXAONE-3.5-2.4B-Instruct (LG AI연구원, 연구·교육용) |
| 파일 | GGUF 형식, Q4_K_M 4비트 양자화 (약 1.0GB / 1.6GB) |
| 실행 도구 | llama.cpp의 파이썬 바인딩 `llama-cpp-python` (CPU 실행) |
| 서버 | Streamlit Community Cloud (CPU 2코어, 메모리 최대 약 2.7GB, GPU 없음) |

서버에 GPU가 없고 메모리가 약 2.7GB라서, 매개변수 15억~24억 개 모델을 4비트로 압축한 파일을 골랐습니다. 16비트로 저장하면 3~4.8GB라 메모리에 들어가지 않습니다. 언어모델을 불러오지 못해도 분석 기능은 그대로 동작합니다.

## 분석 방법

- 데이터의 80%로 학습하고 20%(테스트)로 평가합니다. 지표는 R², RMSE, MAE입니다.
- 선형회귀: 최소제곱법. 비선형회귀: 변수 1개면 다항·거듭제곱·지수·로그 곡선 비교, 여러 개면 2~3차 다항 회귀.
- 인공신경망: 은닉층 64-32, ReLU, Adam. 딥러닝: 은닉층 128-64-32-16, 학습 데이터의 20%를 검증용으로 떼어 조기 종료.
- 신경망은 scikit-learn `MLPRegressor`로 학습하고, 같은 구조의 Keras `Dense` 코드를 함께 보여 줍니다.
